# Alpha 16 recovery

Workspace maintenance removed the uncommitted alpha 16 implementation and its temporary test environment on October 20, 2026. The published alpha 15 main commit was unaffected. Earlier alpha 16 test observations apply to the removed build, not automatically to reconstructed source.

Recovery starts from `a5af7b2684063c95c8a82bc2a306aefe824b26d4`. Changes are checkpointed on main as they are rebuilt. Alpha 16 is not published until the rebuilt installer is verified and delivered. The reference audit remains the feature checklist; a referenced mod is not evidence that its features have been implemented.
