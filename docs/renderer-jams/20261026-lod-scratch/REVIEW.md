## Concrete change and ownership proof

Previously each of three detail levels allocated its own Builder's position/color/normal/index scratch arrays and plane mask. Now a build-local Builder and one largest mask serve all three levels. Builder.flush still copies all returned arrays. finish copies the result list before clearing private part references for the next level. Geometry bounds reset on flush. No scratch is stored globally, in a ThreadLocal, in returned meshes, across worker jobs or in GPU resources. This reduces transient Java allocation; it does NOT reduce returned mesh bytes, resident GPU data or establish lower frame times.

All ten frozen baseline mesh signatures remain exact for flat, cavity, cliff/material, partial8/16water/opaque priority and256-height inputs at signed coordinates/floors. The prior18-part bounds matrix still passes. New checks detect output-array aliasing across levels, retain a saved result through25later serial builds and64parallel jobs, compare parallel/serial signatures, verify the existing4096-height input limit at all three details and prove an interrupted build cannot mutate earlier output. All signatures, vertices/indices/normals/colors/height arrays and min/max remain unchanged. Approved art, saved profiles/geography, player edits and finite quantities are untouched; no shaders, settings, native handoff, simulation, near terrain or provider edits.
