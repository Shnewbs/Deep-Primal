## Implementation

New `V8ChunkGenerationStamp` is a strict, versioned canonical ASCII generation identity for explicit V8 revisions 2–6: signed chunk X/Z, saved-profile fingerprint, revision and CRC32 for accidental corruption detection (not cryptographic authentication). It decodes fail-closed, rejects noncanonical strings, missing/zero identities, invalid revisions and overflow. A new `witnessForNewChunk` adapter converts four authoritative persisted-neighbor observations into the existing V8 border admission contract; generated neighbors must have exactly matching revision, coordinates and profile, and ungenerated neighbors must be explicitly certified with no stamp. UNKNOWN, edited, legacy, duplicate, incomplete or corrupt observations reject. The target must be authoritatively UNGENERATED, not merely unloaded.

Two new optional `DensityChunkMaterializer` overloads (snapshot and r6 vegetation receipt) consume these stamp observations, check saved profile and destination coordinates, then delegate through the pre-existing border gate before density sampling/native writes. Old overloads and saved V8 profile envelopes remain unchanged.
