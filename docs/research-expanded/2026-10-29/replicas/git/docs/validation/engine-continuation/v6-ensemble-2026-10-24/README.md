# R52 — fixed-ensemble V6 deposit audit

Parent: `65705ec9f6eed1c9ecc26e6e8d54cd908707babc` (delivered alpha.27).
This continuation adds an independent verification fixture and compact evidence only.
No production Java, preset, default, saved geography, installer or transport rule changes.
No new runtime defect was reproduced; no speculative product fix is proposed.

## Fresh checks

The final deterministic ensemble checks **116,279,272** voxel queries in **262,144**
columns / **1,024** chunks, four seeds (`0`, `1`, `20261020`, `Long.MIN_VALUE`) and
eight latitude bands. Every query equals a wider 7x7 source-cell oracle using
uncompiled trigonometric ellipsoid tests rather than production quadratic column
clipping. Reversing all eight definitions yields the same selected content at every
query. All 91 observed multi-body eligible voxels retain absolute ID priority.
49 production core sources and the profile/check inputs are verified against their
immutable Git blob IDs before and after compilation/execution. Fresh JDK25 direct
compilation is independent of cached Gradle output. `identity.json` seals class,
fixture, source and result hashes.

The default definition parameters are independently transcribed from the frozen
`TerrainProfile.defaults` snapshot (same IDs, shapes, hosts, radii, depth ranges,
spacing, occurrence, density and palette indices). This is a core field comparison,
not a test of the native profile codec or native palette binding. Those retain the
separate alpha.27 evidence. `TerrainV6Checks` and `DepositPlanChecks` are also freshly
compiled from verified parent source and pass: 8,712 terrain columns, 110,398 cave
cells and 1,559,040 authored-deposit oracle comparisons / 13,631 hits respectively.
No full Gradle build, Minecraft, graphics, performance or new JAR ran in R52.

## Sampling correction and remaining coverage

Initial regularly aligned chunk origins yielded only three ore kinds, even after
expanding each chunk from 16 to 256 columns. That grid was not accepted as a balanced
sample. The final fixture uses fixed-seed `java.util.Random`, independent of terrain
hashes, to select 32 chunks per seed/band across 32,768 longitudinal blocks and a
1,024-block latitudinal stratum. Seeds/bands/sample count were fixed before the final
full-height execution; no ore-location search or feature-conditioned acceptance is
used. The coarse three-block vertical stride missed the final sample's single
emerald voxel, so final coverage examines every integer Y from -372 through the
lower of ground-minus-five and 639. Earlier raw sample records are preserved; they
are sampling diagnostics, not failed product or acceptance tests. This run is not
a latency benchmark and repeats were not selected for timing.

Final counts: coal 10,807; copper 10,181; iron 29,804; diamond 577; emerald 1;
gold/redstone/lapis zero. 51,370 eligible ore voxels and 14 host pairs are observed.
These are **pre-carving core field** counts. Caves, bedrock, soil replacement,
native world height, actual generation, mining and full-world climate weights are
not represented. Deep-like Y bounds are used even in columns outside a saved Deep
world. Neither zero counts nor the sparse emerald result establish absence or a
balance defect in the delivered generator. Previously selected native witnesses
exist for all eight ores. Gold, redstone, lapis and the remaining host combinations
need a deliberately broader, separately attributed native distribution study.

No claim of balanced rarity, complete seed/host coverage, native seam acceptance,
Vulkan/Windows/owner-GPU performance, independent60Hz or full engine acceptance.
Existing water/pressure/LOD and authored-material work remains unfinished.

## Current release evidence reviewed

Read-only review of alpha.27's committed results confirms four Standard/Deep
creation/reopen records with explicit save/stop and no crashes; two software-Vulkan
client records report saved sessions, no VUID lines and no crashes. The package
record confirms Windows segregation/common classes but explicitly has no Windows
runtime test. This run did not independently execute those sessions or inspect their
PNG images. `alpha27-record-review.json` preserves the exact reviewed records/blob IDs.
The delivered archive remains alpha.27, not a new R52 build.

## Reproduction

With an immutable checkout of the parent and JDK25, run:

```
python run.py --checkout /absolute/parent-checkout --java-home /absolute/jdk25
```

Place this evidence directory in a writable isolated parent directory; the runner
copies only the 49 verified core sources, profile snapshot and two checks into its
own locations. It creates `../core`, `../classes` and records here. Java heap is
bounded to512MiB; fixed loops bound the sample. Restored source must match every
recorded Git blob. No game/toolchain or compiled classes are committed.

Next preserve frozen V1–V6 and broaden native rare-host/ore distribution and cave
interaction before changing authoring defaults. Any changed geographic output
requires V7. Continue bounded Vulkan water publication and enabled-view LOD work;
this audit alone closes none of those gates. Lease released after checkpoint.
