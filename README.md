# Deep Primal

A standalone, ambitious survival total conversion for Minecraft 26.x on NeoForge: native geology and climate, primitive technology, metallurgy, demanding survival, and mechanical automation.

**Status:** pre-development design. Exact Minecraft and NeoForge versions are still to be selected. This repository does not yet contain a playable mod or buildable source project.

- [Roadmap](roadmap.md) — milestones, dependencies, acceptance criteria, and decisions needed next.
- [Owner decisions and proposals](docs/design-decisions-2026-10-18.md) — water, transport, maps, survival, hunting, fishing, storage, and follow-up design choices.
- [Design reference](docs/design-reference.md) — detailed systems, natural-material catalogs, configuration, progression, and open questions.

Rendering and custom world generation come first. The mod is standalone and does not require TerraFirmaCraft; referenced mods provide design inspiration, with any code or asset reuse subject to license review.
